## Selected public work

### [PropertEase API](https://github.com/abdousadik/propert-ease-api)

A Symfony API for real estate project management within organization workspaces. Users can belong to multiple organizations with separate Owner, Manager, and Viewer permissions.

The implementation demonstrates:

- Organization-scoped project access, search, pagination, and soft archiving.
- JWT authentication, request validation, and explicit permission checks.
- Transactional membership changes with safeguards against removing or demoting the final Owner.
- MySQL concurrency tests using separate processes and database connections.
- Unit, functional, and integration tests, Docker Compose, and GitHub Actions checks.

Built with PHP 8.4, Symfony 7.4, Doctrine, and MySQL. This personal engineering project is under active development. Cloud deployment and public property listings are planned.
